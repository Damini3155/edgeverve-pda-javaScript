## 🧪 Module Overview

### Module 01 — Basics & Control Flow
Core fundamentals of JavaScript including variables (`let`, `const`, `var`), primitive data types, arithmetic operators, and control flow structures (if/else, switch, for/while loops).

### Module 02 — Data Structures
Manipulating built-in data structures. Extensive coverage of Arrays and Strings, along with Dates and Regular Expressions (RegExp).

### Module 03 — Functions & Objects
Understanding functions in JS. Demonstrates standard function declarations, anonymous functions, ES6 arrow functions, and the basics of JavaScript objects.

### Module 04 — Object-Oriented Programming (OOP)
ES6 Classes, object instantiation, constructors, inheritance using the `extends` keyword, and encapsulating data using access modifiers.

### Module 05 — Async & Callbacks
Advanced asynchronous JavaScript.
- **Callbacks:** Passing functions as arguments, handling async execution.
- **Promises:** Creating Promises, chaining `.then()` and handling errors with `.catch()`.
- **Async/Await:** Modern ES8 syntax for handling asynchronous operations seamlessly with `try...catch` blocks.

### Module 06 — DOM & Assignments
Interaction with the Browser Document Object Model (DOM). Contains HTML and JS paired files to manipulate the DOM dynamically.

## ▶️ How to Run

### Running Node.js Scripts
You can run any of the `.js` files using Node.js in the terminal:

```bash
# Example: Running a basics file
node 01-Basics-and-Control-Flow/01-Datatypes.js

# Example: Running a Promise file
node 05-Async-and-Callbacks/02-Promises/promise1.js
```

### Running DOM Assignments
For the DOM assignments (Module 06), open the `index.html` file in your browser to see the JavaScript in action.
